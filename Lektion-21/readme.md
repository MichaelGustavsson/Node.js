# Dag 21 - REST API QueryStrings och WebSockets

Idag ska vi gå igenom mer om hur vi kan skapa frågor till vårt westcoast-cars REST API.
Vi kommer att titta på hur vi kan hantera frågesträngar i url:er.

Vi kommer även att använda websockets i ett test projekt för att bekanta oss med hur ett punkt-till-punkt(peer-to-peer) nätverk kan sättas upp i en blockkedjelösning. Och se hur vi kan synkronisera vårt lager av bilar.
