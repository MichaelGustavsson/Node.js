# Innehåll kursen Node och Blockchain

## Lektion 1
I första lektionen ska vi bekanta oss med Node.js och framförallt hur vi kan bygga serverlösningar med JavaScript. Lektionen innehåller följande moment:

- Intro till Node där vi sätter upp ett enkelt node projekt
- http-webserver här skapar vi en enkelt webb server applikation och tittar på information som vi kan plocka ut ur anropen till applikationen
- node-fs här tittar vi på hur vi kan använda serverns filsystem för att skapa och ändra kataloger samt filer.
- json-server projektet, här skapar vi ett enkelt REST-API med node.js http modul.

## Lektion 2
Under lektion 2 går vi vidare och tittar på bättre och enklare alternativ till node.js egna http module och installerar biblioteket express.js. Som underlättar vårt arbete med att skapa webb server applikationer och rest baserade api applikationer.

## Lektion 3
I lektion 3 går vi igenom hur vi skapar en korrekt struktur för vårt rest api baserat på design mönstret MVC. Vi skriver om applikationen ifrån lektion 2 till ha en mer korrekt struktur som gör det enklare att göra förändringar och att underhålla.

## Lektion 4
I lektion 4 introduceras vi till *middleware* och felhantering

## Lektion 5
Lektion 5 handlar om att arbeta testdrivet med hjälp av testbiblioteket *vitest*

Vi börjar även gå igenom databashanteraren *MongoDB* som är en dokumentdatabas. Vi installerar mongodb lokalt på våra maskiner och börjar med att använda mongodb's egna drivrutin *mongod* för att arbeta med **CRUD** operationer.

## Lektion 6
I lektion 6 ska vi titta på ett alternativ till *hardcore* mongodb anrop och istället installera *mongoose* som är ett *odm* bibliotek som underlättar **CRUD** operationer i mongodb.
