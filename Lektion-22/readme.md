# Dag 22

### Relationsdatabaser med Node.js

Idag går vi igenom hur det går till att använda relationsdatabaser tillsammans med Node.js

Relationsdatabaser är än idag det mest populära valet av datalagring hos de flesta företag tack vare dess sätt att effektivt lagra data och minimera riskerna för inkonsekvent data.

#### Sqlite

Vi kommer att använda Sqlite som relationsdatabas i vårt exempel.

Sqlite är en filbaserad databashanterare vilket betyder att vi endast har en fysisk fil som är vår databas.

Den är väldigt enkel att använda och gör vi något fel är det bara att radera filen och börja om igen.
